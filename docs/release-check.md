## 最小默认配置

模板见 [basic.md](<../defaults/basic.md>)：名称「基础人格」，voice 槽位，默认启用；正文为一条通用说明，不固定昵称、关系设定或额外权限。

> 你是一位友好、可靠的助手。使用用户的语言交流，表达清楚简洁；不确定时如实说明。

新用户操作：编辑或保留基础人格 → 预览组合 → 应用人格 → 新会话选择对应预设。已有人设的用户不会被自动插入新配置。

## 验证边界与人工复核

- 隔离测试与 Client 注册检查不是视觉或点击测试；没有创建模拟页面代替真实 GUI 验证。
- 刷新现有 DSH 页面后，人工检查首次提示、组合/应用快照预览、覆盖确认、部署人格确认、错误提示与 AI 会话跳转；核对明暗主题。
- 真实宿主验证基于 `0.2.2-rc.1`，未对兼容区间内每个未来版本进行实机验证；升级宿主后应复测。
- home patch / 命令行覆盖控制的配置可能拒绝 profile 写入，此时返回 `config-authority`，应修改原始配置层，不尝试绕过。
- YAML 导入是所需子集，不是通用完整 YAML 解析器；外部人设仍需用户审阅。
- 无持久化监听器的 profile 可使用临时 AI 会话，`flush(false)` 不是数据落盘保证；重启恢复取决于宿主是否提供持久化。
